Frida Core 17.17.0 (frida-core devkit, windows-x86_64)
License: LGPL-2.0 with WxWindows-exception-3.1

runtime/dam-link.exe statically links the unmodified frida-core devkit
(frida-core-devkit-17.17.0-windows-x86_64.tar.xz). The archive SHA-256 is
pinned in tool/release.json, and the same file is used for every build.

Frida umbrella source and corresponding subprojects:
https://github.com/frida/frida/tree/17.17.0
https://github.com/frida/frida-core
https://github.com/frida/frida-gum

The release SOURCE archive also contains the exact 17.17.0 source archives:
frida-17.17.0.tar.gz
frida-core-17.17.0.tar.gz
frida-gum-17.17.0.tar.gz

The source of dam-link.exe itself is native/dam-link in the project source,
so the program can be relinked against a modified frida-core.
